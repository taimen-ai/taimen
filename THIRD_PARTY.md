# Third-party software

This repository contains no third-party code: the scripts in `tools/` and `deploy/`
use only the Python standard library. The third-party dependencies of each Taimen
component are listed in the `THIRD_PARTY.md` file of the component's repository (for
Python components it is generated by `tools/generate_third_party.py`).

Below is the third-party software that the assembly uses but does not distribute:
container images that `deploy/local/compose.yml` pulls from registries, and the tools that build
the guide. Each is distributed under its own licence.

| Software | Where it is used | Licence |
|---|---|---|
| PostgreSQL (`postgres:16-alpine`) | service databases | PostgreSQL License |
| MinIO (`minio/minio`) | storage for artifact contents | AGPL-3.0 |
| MinIO Client (`minio/mc`) | one-time bucket setup | AGPL-3.0 |
| Caddy (`caddy:2-alpine`) | the edge and serving the guide | Apache-2.0 |
| Keycloak (`quay.io/keycloak/keycloak`) | the optional `idp` profile | Apache-2.0 |
| MkDocs | building the guide `guide/` | BSD-2-Clause |
| Material for MkDocs | the theme of the guide `guide/` | MIT |

MinIO and MinIO Client run as separate processes in their own containers and interact
with the platform over the network (S3 API); the platform code does not link with
them. Any S3-compatible storage can be used instead of MinIO (`CP_S3_ENDPOINT_URL`).
